# A Paleogenomics Taxonomy

A curated, read-only export of a single domain from a larger private research taxonomy — ancient DNA (aDNA) research on early modern human dispersal, archaic admixture, and population genetics of the Late Pleistocene. Anchored by Sümer et al. (2024, *Nature*), the Ranis/Zlatý kůň study.

This is a one-way publication: no accounts, no merge, no ongoing governance. The private taxonomy this was drawn from stays exactly as-is; this is a periodic, curated export of one self-contained subtree.

## Sourcing & methodology

This section is cross-confirmed across 5 independently-synthesized source documents within a single processing batch, drawing on the same primary peer-reviewed source (Sümer et al. 2024). Full sourcing and provenance notes are inline in each page.
